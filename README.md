# 🛠️ UnityGameSystems

面向多个 Unity 项目的可复用游戏系统库，各模块均以独立 Unity Package 提供。

## 📦 模块列表 (Packages)

| 模块 | 描述 | 文档 |
| --- | --- | --- |
| **Health** | 生命、伤害、治疗、死亡与复活 | [查看详情](./Packages/com.computerzhuxi.health/README.md) |
| **Perception 2D** | 2D 视觉、听觉与感知记忆 | [查看详情](./Packages/com.computerzhuxi.perception2d/README.md) |
| **Navigation 2D** | 2D 路径查询、导航与局部避让 | [查看详情](./Packages/com.computerzhuxi.navigation2d/README.md) |
| **Stats** | 属性定义、修正计算与业务值绑定 | [查看详情](./Packages/com.computerzhuxi.stats/README.md) |

安装方式、快速开始和使用示例请查看对应 Package README。

## 📂 仓库结构 (Repository)

- `Packages/` — 正式 UPM 包
- `Projects/` — 各包的开发与验证工程
- `Documentation/` — 仓库级文档
