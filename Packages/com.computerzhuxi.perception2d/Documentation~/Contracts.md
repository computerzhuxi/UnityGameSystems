# 感知契约与边界（0.2.0 候选）

## 所有权与身份

`PerceptionTargetRegistry` 负责目标身份。句柄含注册表归属、目标编号和生命周期代次；可关联任意外部对象，但核心和注册表不读取其位置。多个观察者共享注册表，各自的核心独立持有记忆。注销使旧句柄无效并释放活动条目；仍在外部存活的关联对象通过弱身份映射保留对象池编号和代次，无关联目标注销后也不再占用活动条目。同一对象重新注册产生新代次，旧句柄不复活。错误注册表输入明确抛异常，排队后才失效的输入丢弃。`PerceptionWorld2D` 提供组件路径的共享注册表、映射和声音路由；纯 API 不要求 World 组件。公共 API 只承诺 Unity 主线程使用。

核心 `PerceptionCore2D` 是唯一状态、记忆、查询和事件实现。它不依赖 GameObject、MonoBehaviour、Transform 或 Physics 查询。内部轨迹及命令队列不直接暴露。视觉、听觉配置由 `PerceptionSettings2D` 验证复制；`Settings` 查询返回防御性副本，运行中只有 `UpdateSettings` 可提交配置变更并保留记忆。范围、时间、响度和向量必须有限；范围和时长非负，视角 0–360，丢失距离不小于发现距离，扫描间隔至少 0.02 秒，匿名声音记忆必须大于零。

## 时间与完整视觉帧

调用方为核心输入和推进提供同一条单调时间轴；非有限数与倒退抛参数异常。非法输入不会推进时间水位，陈旧视觉来源及失效目标输入丢弃且不推进时间水位。组件使用缩放时间，暂停不推进、不扫描，长帧最多扫描一次。已确认的旧记录不被更早事实覆盖。

一次 `SubmitSightFrame` 是该核心当前视觉来源的完整结果。**未提交帧无新结论**，不会自动 Lost；空帧结束全部当前视觉；非空帧更新帧内目标并结束缺席目标。输入在提交时复制，调用方可复用缓冲；相同句柄去重。持续看到会更新位置和最后观察时间，不重复 Acquired。丢失后保留最后成功位置和时间。每核心只有一个有效视觉来源，多来源由外部合并。停止视觉来源须调用 `EndSightSource`；切换来源时来源代次立即变化，旧排队或延迟帧不能复活目标。视觉来源代次独立于目标身份代次。

默认 `PhysicsSightScanner2D` 只进行一次扫描，返回完整帧，不直接改记忆。组件默认从所属 Scene 获取 `PhysicsScene2D`，也能显式覆盖；候选查询和遮挡检测必须使用同一场景。独立目标与障碍 LayerMask、发现/丢失距离迟滞、视角、单检测点、Collider 去重和可增长复用缓冲适用。Trigger 目标可被发现；Trigger 障碍不遮挡；观察者自己及目标自己的 Collider 不遮挡，其他障碍起点命中也遮挡。迟滞只读取核心当前视觉状态。扫描器、物理场景或手动模式切换结束旧持续视觉，保留记忆和听觉，并安排下一次扫描。组件所属 Scene 变化也触发来源切换。运行时改参数保留核心和记忆，安排立即扫描。

## 听觉、记忆与查询

默认声音由 `World.ReportNoise` 在上报时按监听者开关与 `min(HearingRange × Loudness, MaxRange)` 筛选，再提交核心。零响度不投递。核心 `ReportHearing` 是已确认听到的事实，不做二次距离检查。不依赖实际音频播放、方向、障碍或声学传播。来源声音进入该代目标的听觉记忆；无来源声音用独立事件 ID 和有限记忆。每条有效声音发布 Heard，同目标只保留最新一条听觉记录。

视觉和听觉独立保存。当前视觉不过期；丢失视觉从最后成功观察时间计时；目标记忆时长零表示无限。无来源声音始终按 `AnonymousMemory` 过期。综合位置优先当前视觉，否则选择时间最新的有效记录，同时间按 `DominantSense`。位置只来自成功输入，不读取不可见对象的实时位置。持续声音不会被误表示为 `IsCurrent`。

## 批次、事件与重入

每批顺序为输入命令、身份与来源验证、状态更新、过期清理、查询视图与版本提交、事件发布。`SenseUpdated` 先于 `TargetForgotten`，最后是 `ObservationsUpdated`。事件回调读取最终状态；回调内修改进入下一批；重入 `Advance` 抛异常。每个订阅者异常记入 Unity 日志，其余订阅者继续。整体遗忘只在该生命周期的最终状态无任何感官记录时发布；同批重获同代目标不发布整体遗忘。

关闭视觉发布 `SenseDisabled` 并结束当前视觉，保留记忆；关闭听觉不制造声音结束事件。非回调关闭听觉立即阻止后续默认声音接收。重新开启视觉立即安排发现距离扫描，不补发听觉。清理记忆不改变开关；仍开启视觉时后续完整帧可重新发现。`ResetForReuse` 取消已排队旧输入并恢复默认开关；组件先提交一批重置，下一次推进立即用发现距离扫描，再接受新生命周期输入。目标注销在各核心下一批触发 `TargetInvalidated`。来源切换结束视觉时用 `SourceChanged` 区分原因。查询列表为复用只读视图，不可跨更新枚举。

## 非目标范围

本包不负责地图楼层、阵营、AI 决策、导航、隐身游戏规则、声学传播、网络/存档身份、后台线程扫描、多检测点、多视觉源自动融合、空间索引或任意感官插件。默认组件只提供视觉、听觉和记忆；游戏规则在消费项目处理。
