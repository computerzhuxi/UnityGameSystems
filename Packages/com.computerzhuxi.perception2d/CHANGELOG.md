# Changelog

## Unreleased

- 已激活 World 收到 Unity `OnDestroy` 时失效全部活动注册身份，核心在后续批次按既有流程清理；目标可在 World 先销毁后安全停用或重新绑定。从未激活的 World 仍需身份所有者显式解绑目标。
- 明确已接受视觉帧在来源切换后仍保留单调时间水位，补充定向契约与生命周期测试。
- 增加双入口上手文档，统一 Sample、Lab 与构建流程的职责说明。

## 0.2.0 — 未发布候选

- 新增 `PerceptionTargetRegistry`、生命周期句柄及普通 C# `PerceptionCore2D`，多个观察者可共享身份并独立持有记忆。
- 视觉改为完整帧输入；独立 `PhysicsSightScanner2D` 在指定二维物理场景扫描，组件默认自动使用所属 Scene 的物理场景。
- 声音由 World 完成默认距离筛选后交给核心；核心也可直接接收已确认的声音。
- 支持运行时更新参数、切换扫描器/物理场景、手动视觉输入和来源代次隔离；切换视觉来源保留听觉与记忆。
- 保留原组件序列化字段和便利查询；新增来源变化原因 `SourceChanged`。跨 World 绑定因注册表变更会建立新核心并清除旧环境记忆。
- 公共 API 和行为从 0.1.0 发生变化；迁移说明见 [README 的迁移说明](README.md#迁移说明)。
- 复核修正：配置查询改为防御性副本，失败/陈旧输入不推进时间水位，注册表注销释放活动条目；组件恢复与重置立即安排发现扫描，换核心后解除旧事件转发。

## 0.1.0 — 2026-09-14

- 新增二维视觉、事件式听觉、独立启停和按目标/感官记忆。
- 新增显式环境绑定、生命周期代次、无来源声音和异常隔离事件。
- 新增独立示例、EditMode/PlayMode 验证及 ARPG 视觉接入。
