# Navigation2D 0.2.0 范围与兼容矩阵

依据：用户先选择地面行走，再明确本轮做好 2D，3D 留作未来方向；已批准设计见 [NavigationEvolution](../../../Design/NavigationEvolution.md)。本记录描述实际 2D 候选，不把早期泛型/3D 草案算作实施要求。

## 两层职责

1. 包：保留 A* 查询，增加可选普通 C# Agent，拥有导航任务、路径、索引、时钟与移动建议；可选组件提供 Inspector、物理源与生命周期。
2. 项目：Enemy 决定目的地，World 提供正式层级对应障碍域，EnemyNavigation 转发指令及速度倍率，CharacterMovement2D 执行移动。只有 Agent 拥有跟随状态。

无需独立 Core 程序集：本轮稳定使用 Vector2 和现有 Unity 物理契约，没有已验证的纯 .NET 消费者。组件不会自动 Update/Tick，也不写 Transform 或 Rigidbody。包不引用 ARPG，不向其测试开放内部实现。

## 兼容矩阵

|行为|0.1.0|0.2.0 候选|
|---|---|---|
|直接 FindPath|完整路径输出及明确失败原因|签名、结果、A* 和数据归属不变|
|跟随状态|ARPG EnemyNavigation 私有实现|可选公共 Agent 独占；适配层不复制|
|移动目标阈值|相对最近查询终点累计|保持|
|成功重算时机|目标达到阈值后立即重算|按最小间隔节流；ARPG 复用原 0.25 秒配置|
|失败重试|0.25 秒重试|保持 ARPG 间隔，包可独立配置 FailureRetryInterval|
|起点中心回头抖动|项目完整扫掠后跳过首中心|该稳定语义移入 Agent，完整查询输出不变|
|到达容差切角|保留必要转角|保持，并由包公开 API + Physics2D 验证|
|动态封路|立即重算或停止|立即停止，等待剩余间隔重算；已知变更可主动失效|
|同格终点|查询检查完整连线|保持；Agent 到达也检查整段净空|
|调查完成判定|项目距离容差|保持，不额外把包到达语义强加给玩法状态机|
|暂停|项目 TimeScale 早退|保持；包增加 Pause/Resume 与零 dt 不推进|
|正式空间层变化|项目域版本导致旧路径失效|由适配器传源/版本/有效性，Agent 清除旧路径|
|楼梯预览/取消|World 不提交层变化|保持，无自主寻找楼梯|
|Scene/Prefab/配置|现有身份和字段|ARPG 不迁移类型、不改资产和 GUID；新增 Lab 场景及组件|

## 风险与验证方向

- 节流改善请求密度，但不能保证毫秒截止，也可能增加移动目标响应延迟；保留真实控制器测试并要求人工观察。
- 移动建议仅在查询时刻安全。执行器仍需碰撞与步长限幅，传送应主动 InvalidatePath。
- 只读路径是实时视图，不是快照。外部不得复制索引继续推进同一角色。
- Physics2D 同步由消费者负责，未引入跨查询缓存；源回调异常传播且代理清零建议，实例可恢复。
- 多层 XY 重叠由项目选择障碍域；包不知道 World 类型。跨层路线、地面存在、自动脱困、群体避让、重力跳跃和 3D 本轮均不实现。
- 性能先测量：保留原 A*，测稳定跟随、多角色移动目标及真实物理搜索，不宣称未经对照的单次提速。
