# Navigation2D：可选多角色局部避让

日期：2026-09-17。用户已批准先做 2D 局部避让，战斗站位留在 ARPG；本设计扩展尚未发布的 0.2.0 Agent 候选。禁止提交、标签、推送，保留既有改动。按仓库 DevelopmentWorkflow 在唯一正式包及现有 Lab 开发，不搬动正在评审的候选。

## 目标与边界

解决同层敌人在可绕行空间中被其他敌人挡住的问题。GridPathfinder2D 仍负责环境路径，NavigationAgent2D 仍唯一拥有路径/目标/索引/重算时钟。新增可选 AvoidanceWorld2D 批量计算建议速度，不拥有 Transform、刚体、游戏状态或目的地。输入调用方每步快照，不建立第二套位置模拟。

ARPG 负责决定走向何处、映射物理场景及已提交空间层、采集位置/实际速度、保留动作/击退优先级，并通过 CharacterMovement2D 提交普通运动。停止、攻击、受击角色仍作为邻居；不可自主移动者不承担避让责任。生命周期通过每步输入集合解决，移除对象不残留。

不包含：战斗槽位/攻击名额、自主上下楼、跨层路径、3D、自动脱困、地面存在检测、完备的拥堵调度。所有人追同一点仍可能拥挤；窄到不能会车时可以停下，不承诺永不死锁。

## 方案与资料

- 不把 Actor 层并入全局 Physics2D 障碍掩码：会包括自身/目标，不能替代局部速度规划。
- 不采用仅相斥向量：缺少对未来碰撞和停止对象的约束，易抖动。
- 采用 ORCA 速度约束作为首选实验；公开 API 不暴露第三方类型，静态地图仍通过现有 ITraversalSource2D 检查实际移动段。
- 官方 RVO2-CS：https://github.com/snape/RVO2-CS ，固定研究提交 a455da254cffd9ebb8d85f8eedb9d9332e69012a，Agent.cs 与 LICENSE 已核对 Apache-2.0。若改编代理约束/线性规划，保留版权、完整许可证和变更说明；不导入全局单例、多线程模拟器或 .NET 10 项目。
- A* Pathfinding Project：https://arongranberg.com/astar/documentation/stable/localavoidance.html ，仅参考共享求解器与运动分离职责，不复制商业代码。
- Godot：https://docs.godotengine.org/en/stable/tutorials/navigation/navigation_using_navigationagents.html ，参考 desired/safe velocity 与实际运动分离。

## 公共契约方向

AvoidanceWorld2D 接收一批具有稳定 ID、通用 Group、位置、实际速度、期望速度、圆形半径、最大速度及是否受外部控制的快照，输出同序建议速度和邻居截断/不可行诊断。实例只复用邻域索引、约束及结果工作缓冲；不更新位置，不调用游戏逻辑。最大代理数与最大邻居数明确限制资源，稳定 ID 打破同距离排序；无同实例重入。非法输入明确异常且不得部分更新结果。

共享邻域索引避免每个敌人各自扫物理场景。地图约束校验发生在实际运动前；裁剪/停步及物理碰撞会改变 ORCA 输出，因此不得宣传无条件数学无碰撞保证。实际速度下一步重新采样。

## ARPG 行为兼容

|行为|决定|
|---|---|
|单角色路径、重算、到达、异层决策|保留现有生产测试|
|同层多敌人可绕行|新增批量避让；验证真实控制器与刚体|
|不同已提交空间层|互不参与避让；楼梯预览不提前切组|
|停止/攻击/击退|继续作为邻居；不改动作控制权|
|物理碰撞矩阵|保留，不全局禁用角色碰撞|
|场景/Prefab/配置字段与 GUID|保留，优先运行时接入|
|速度/路径状态|Movement 与 Agent 各自唯一拥有|

## 验收

算法：单体、迎面交错、停止障碍、不同半径、同 XY 不同组、输入顺序确定性、重叠、非法值/重复 ID、容量/邻居预算、预热分配与性能。真实物理：薄墙、转角、窄道、动态障碍、连续移动目标、停止/受击/注销/跨层。Lab 新增可见多角色场景，人工观察通行、停止与拥堵边界。完整 EditMode/PlayMode、Sample 独立导入、空 Library、Standalone、ARPG dotnet/资产/DLL/meta/GUID、文档图生成与人工复验。
